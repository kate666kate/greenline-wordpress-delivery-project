How To Explain This

Website action
GTM event
Google Tag Manager
GA4 report
Google Analytics 4
  • GA4 (Google Analytics 4) is where the client sees reporting: page views, button clicks, form submissions, and conversions.
  • GTM (Google Tag Manager) is the manager that listens for events and sends them to GA4 without changing theme code every time.
  • dataLayer is a JavaScript array where website actions can be pushed in a structured way.
  • Never send private form content such as names, emails, phone numbers, or full messages to GA4.
  • CTA (Call To Action) means an action button or prompt, such as "Request a Consultation".
