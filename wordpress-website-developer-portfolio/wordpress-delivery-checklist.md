# WordPress Delivery Checklist

Use this before handing a site to a client or before saying a migration is complete.

## Content

- All required pages exist.
- Homepage is set correctly.
- Navigation menu is correct.
- Footer links are correct.
- No placeholder text remains.
- Contact details are correct.

## Forms And Email

- Contact form submits successfully.
- Notification goes to the correct internal mailbox.
- Auto-reply, if used, goes to the customer.
- From address uses the site/client domain.
- Reply-To uses the customer form email.
- SMTP is configured.
- Real mailbox test is complete.

## SEO

- Clean permalinks are enabled.
- Each page has one H1.
- SEO title is unique and clear.
- Meta description is unique and useful.
- Images have alt text.
- Sitemap exists.
- Robots.txt does not block indexing.
- Search engine visibility is enabled.

## Images And Performance

- Large images are compressed.
- Images use suitable dimensions.
- Important content images have width and height attributes.
- Below-fold images lazy load.
- Unused plugins are inactive or removed.
- Cache plugin is configured.
- Page speed has been checked.

## Hosting, DNS, And SSL

- DNS A record points to the correct server.
- www record points correctly.
- MX/TXT email records are preserved.
- SSL certificate is valid.
- www and non-www are covered by SSL.
- HTTP redirects to HTTPS.
- Live domain loads the new site.

## Migration

- Old site backup is kept.
- New site import is complete.
- Permalinks are refreshed.
- Old URLs are replaced where needed.
- Media files display correctly.
- Admin login works.
- Forms work after migration.
- Old site is placed in maintenance mode or retained for rollback.

## Backup And Security

- Full backup exists.
- Backup includes database, uploads, plugins, and themes.
- Admin passwords are strong.
- Unused admin users are removed.
- Unused plugins/themes are removed.
- Security plugin is configured if required.
- Application passwords are revoked when no longer needed.

## Troubleshooting Checks

- cPanel error log checked if needed.
- WordPress debug log checked if needed.
- Plugin conflict recovery path is known.
- Database connection settings are known.
- PHP version and PHP limits are checked.
